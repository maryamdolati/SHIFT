# Third-party code and data

SHIFT uses the published KRNO operator library and the benchmark pipelines linked in UPSTREAM_SOURCES.json. The original KRNO library has a GPL-3.0 license in the supplied upstream archive. Retain that license and attribution when redistributing upstream code; this repository does not bundle the upstream library or dataset files. Before public release, confirm the license for the new SHIFT code and its compatibility with all dependencies. No license is assigned to the authors' unpublished work by this reconstruction.

MIMIC-III is access-controlled; never commit patient records, record identifiers, prepared clinical arrays, raw logs, or credentials. Use external data paths and honor each benchmark's data-use terms.
